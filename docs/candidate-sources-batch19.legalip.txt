# Every row below PASSED native/tools/probe_hp_batch.py over the wire.
#
# Note on plain XML. Several of the best primary legal publishers in this space
# serve XML and nothing else -- Germany's rechtsprechung-im-internet rii-toc.xml
# (23 MB, every published federal judgment), rechtspraak.nl's Waardelijst court
# registers, Finlex's Akoma Ntoso statute corpus, laws-lois.justice.gc.ca's
# Legis.xml, althingi.is, and the legislation.gov.uk /data.feed Atom set. The
# prober's count_xml() accepts them, but lib/hpengine.c has exactly three
# readers -- hp_run_json, hp_run_csv and hp_run_html -- and none parses XML, so
# a registered XML row would fetch 200 OK and emit nothing on every run for
# ever. That is the EMPTY_RESULTSET trap wearing a different hat, so those
# endpoints are deliberately NOT in this file. They are in the handover note
# instead, and become available the day the engine grows an XML reader.
