# Batch 21 - healthpay: the CMS Open Payments transparency database, as a
# NAMED-PHYSICIAN pivot.
#
# SCOPE. openpaymentsdata.cms.gov appeared in the tree twice: the bare
# /datastore/query/ base and the metastore item list, plus one 2021 general
# payment dataset. Open Payments is a per-year set of 26 datasets and the
# ownership, research and profile tables - the ones that name which doctors
# hold an investment interest in which manufacturer - were not reachable at all.
#
# This is the United States register of every payment a drug or device
# manufacturer made to a named physician or teaching hospital, published under
# the Physician Payments Sunshine Act. It is a conflict-of-interest register
# with the physician's name, NPI, address and speciality attached.
#
# MEASURED COST. The general and research payment tables are 10-million-row
# scans: one page of 500 records took 71 seconds for a 2024 last-name query and
# 75 seconds for 2025. Those four rows therefore declare page_max=2 - two pages
# covered the 852- and 825-record results the probes returned in full - and the
# engine stamps the ceiling on every record when it bites. The ownership and
# profile tables answer the same query in one to nine seconds and page normally.
#
# The ownership tables store the physician surname in MIXED case while the
# general and research tables store it UPPERCASE, so the ownership rows pivot
# on {q} and the payment rows on {qU}. That was measured, not assumed: a {qU}
# query against the 2019 ownership table returns zero records for a surname
# that is present in it.
#
