# It was probed live and REJECTED in batch 33 for one reason only: it is NDJSON
# (one complete JSON value per line, no enclosing array, no commas), and
# hpengine had no mode for it. docs/rejected-sources-batch33.tsv names this
# feed as "the one rejection worth fixing in the engine rather than working
# around". HP_NDJSON is that fix, and this is the row it exists for.

# see docs/rejected-sources-batch34.tsv. Its path is SHARDED by crate name
# (serde lives at /se/rd/serde) with four different layouts depending on the
# name's length, and a declarative row cannot hold that branching — the same
# reason CLAUDE.md gives for not converting VJSON_PREP.
