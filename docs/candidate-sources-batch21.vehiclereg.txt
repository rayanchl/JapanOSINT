# Batch 21 - vehiclereg: the Dutch national vehicle register (RDW) as a LICENCE
# PLATE pivot.
#
# SCOPE. The tree already fetched 24 RDW Socrata resources, every one of them as
# a bulk `?$limit=1000` head-of-table read, and not one of them keyed on a
# vehicle. RDW is the only European national vehicle register that answers a
# plate query anonymously and without a key, and the plate is the entity an
# analyst actually has. The main vehicle table alone (m9d7-ebf2) was not in the
# tree in any form.
#
# Every row below was confirmed by taking a real kenteken out of the table's own
# first record and querying it back; the probe URL for each row is that plate.
# The four recall tables key on RDW's recall reference code and the two trade
# tables key on the business sequence number and the postcode.
#
# PAGINATION. A per-vehicle query returns single-digit record counts (the
# largest measured here is 8 observed defects for one lorry), far below
# Socrata's 1000-row default page, so those rows declare `pagination_ok` with
# that measurement rather than spending a second request that always returns
# an empty page. The one bulk row - the defect code register - pages with
# $offset.
#
# Three of these datasets (2ba7-embk, 7ug8-2dtt, 3xwf-ince) are already read as
# static `?$limit=1000` bulk feeds by collectors/feed/generated/
# vsrc13_europe_data_6.c. Those feeds read the first 1000 rows of tables holding
# 559,856 and 575,707 records and cannot reach a specific vehicle at all, so the
# plate pivots below are not a second copy of them. A fourth (3xwf-ince,
# tracked-vehicle running gear) holds only 547 rows, which the existing bulk
# feed does cover in full - that row was written, measured and REMOVED for that
# reason and is in the rejects file.
#
