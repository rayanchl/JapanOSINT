# Batch 20 - scholarly: research literature registries the tree had not reached.
# Crossref, OpenAlex, DataCite, OSF and Zenodo are already saturated here; what was
# missing was the non-Anglophone and discipline-specific corpora - SciELO's Ibero-
# American national collections, Europe PMC's preprint and book streams, INSPIRE's
# seminar and dataset records, PLOS's own Solr index and dblp's author and venue
# indexes.
# Pipe-delimited. Columns: id|mode|want|category|record_type|tags|portal|name|name_ja|url|probe|description|opts
#
# Engine notes for this beat:
#  * Europe PMC publishes a cursorMark `nextPageUrl` in every search response, so
#    those rows page with next_path rather than an offset the server would reject
#    past 1000 hits.
#  * PLOS and ORCID page on `start`, which is 0-based but does NOT contain the
#    substring "offset", so the engine would coerce page_start to 1 and skip a
#    record at every page boundary. page_zero_based=1 is set on both.
#  * dblp pages on `f` (first hit) with `h` as the page size - also 0-based.
#  * the SciELO articlemeta identifier endpoints return only code/collection/
#    processing_date. They are useless without their detail hop, so every one of
#    them declares it; the second hop is what carries the actual bibliographic
#    record.
