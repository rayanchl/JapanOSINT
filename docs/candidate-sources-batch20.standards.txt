# Batch 20 - standards: measurement, metrology and Internet standards bodies.
# The tree already had IANA, W3C and the core of the IETF datatracker; what was
# absent was the BIPM key comparison database (the world's measurement traceability
# register), the RFC Editor's own errata and index files, and the datatracker
# tables that describe the PROCESS - the person register, the document event log,
# directorate review requests and the nominating committee - not the documents.
# Pipe-delimited. Columns: id|mode|want|category|record_type|tags|portal|name|name_ja|url|probe|description|opts
#
# Engine notes for this beat:
#  * the datatracker pages on `offset` with `limit` as the page size. "offset"
#    contains the substring the engine looks for, so page_start stays 0 without
#    a page_zero_based declaration - it is declared anyway so the intent is
#    readable in the manifest rather than inferred from the engine's source.
#  * www.bipm.org/api/kcdb/referenceData/* returns the whole reference list in one
#    response and has no paging parameter of any kind; pagination_ok records that
#    as measured rather than leaving those rows permanently flagged.
#  * the RFC index is XML and its record element is <rfc-entry>; declaring
#    array_path avoids the auto-detector picking the more numerous <doc-id>.
