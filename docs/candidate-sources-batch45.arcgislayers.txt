# Batch 45 beat arcgislayers — 164 ArcGIS feature layers, MEASURED LIVE (2026-10-19).
#
# THE METHOD, which is the reason this batch exists: ask each service root for its own DIRECTORY
# (`<root>?f=json` -> folders, services; `<root>/<svc>/<type>?f=json` -> layers and tables) instead of
# requesting a layer path somebody happened to know. This is batch 42's WordPress route-table method on a
# different family. The tree already reached 195 ArcGIS roots, each by ONE row naming ONE layer; their
# directories advertise thousands of services — one root alone published 899. 899 candidate layers were taken
# (capped at 5 per root, a bound this batch chose, not one the hosts imposed), 819 probed PASS, 456 survived a
# 50-record floor plus dedupe plus dropping cartography, and 164 were selected at 2 per root.
#
# Every field here was measured, not assumed:
#   id_keys     the layer's OWN objectIdField (several use FID, not OBJECTID). Rule 4b fails silently.
#   page_size   the layer's OWN maxRecordCount, capped at 2000. resultOffset is a record OFFSET, so page_size
#               belongs on it (this is the case `make lint-sources`'s page-size-on-page-number check separates).
#   orderBy     ascending on the object id: 34 of these rows carry page_resume=1 and ArcGIS promises no stable
#               ordering without one. An unstable order under a resumed walk re-reads or skips at every seam.
#   geometry    per geometry type, measured each way. Point and polyline: full geometry in WGS84 (polyline
#               paths cost 1.3x-9.3x). Polygon: returnCentroid, because rings measured 64x (125 KB -> 8.0 MB per
#               200 records) for coordinates HP_JSON cannot index anyway, and a centroid is 1.7% of that.
#               returnCentroid works ONLY on polygon layers — ArcGIS says so with HTTP *200* and a 216-byte
#               error body, which is why all 18 polyline rows first came back PATH_UNRESOLVED.
#               Non-spatial tables ask for no geometry; the one multipatch layer was dropped.
#
# name_ja is empty on every row, deliberately: the format allows it, and 164 machine translations of agency and
# layer names would read as authoritative with nothing in the tree able to catch a wrong one.
#
# Gates: batch_exclusions --check --bin (1 collision + 1 near-miss, both read by hand, both FALSE POSITIVES —
# the tool matched "airspace", a record_type literal in av_faa_arcgis.c, as a dataset name; Airspace/ATSRoute/
# Class_Airspace hold 16,789/52,096/6,045 records and are three different collections), audit_batch_pagination
# 0/164, audit_batch_reachable 0/164, probe_hp_batch 164/164 PASS, audit_batch_emit see
# docs/verified-sources-batch45.tsv. Rejects kept as data in docs/rejected-sources-batch45.tsv.
