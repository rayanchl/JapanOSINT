# Batch 24 - jpbbs: the 2ch-family regional and general boards.
# Also discovered live in batch 23 and dropped: subject.txt is Shift_JIS on
# every one of them and lib/hpengine.c had no transcode on its fetch path,
# so the titles would have been stored as mojibake. The engine now
# transcodes a non-UTF-8 body from a .jp host, gated exactly as
# lib/feedlib.c gates it, so these are registerable.
# 5ch.net and jbbs.shitaraba.net still answer 403 to this host and are
# still absent - that is a refusal, not an encoding problem.
# Note the two different field separators: machi.to uses a comma (verified:
# 0 of 639 titles contain a second one) and open2ch uses <>.
# Pipe-delimited. Columns: id|mode|want|category|record_type|tags|portal|name|name_ja|url|probe|description|opts
