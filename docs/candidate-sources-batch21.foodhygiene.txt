# Batch 21 - foodhygiene: the UK Food Standards Agency's Food Hygiene Rating
# Scheme API.
#
# SCOPE. api.ratings.food.gov.uk appeared in the tree exactly once, as a
# name search. The API has ten other endpoints and roughly 600,000 inspected
# establishments behind them, keyed on the local authority that inspected them,
# the business type, the rating awarded and the address - none of which was
# reachable.
#
# TRAP. Every endpoint answers `"The API 'Authorities' doesn't exist"` with
# HTTP 404 unless the request carries `x-api-version: 2`. That is a version
# negotiation failure reported as a missing resource, and without the header a
# discovery pass concludes the whole API is gone. Every row declares it, and
# tools/probe_hp_batch.py sends the row's own headers, so each row here was
# proven under exactly the request conditions its collector uses.
#
# REJECTED for cause: `/Establishments/basic` returns the same first 1000
# records for pageNumber=1 and pageNumber=2 - it accepts the parameter and
# ignores it. Declaring page_param on that row would make the engine refetch
# page one until the page ceiling, which is the exact failure CLAUDE.md
# describes for a positional next_path. It is in the rejects file.
#
