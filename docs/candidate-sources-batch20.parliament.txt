# Batch 20 - parliament: legislature open data the tree had not reached.
# The Nordic, Irish, Swiss, Brazilian and European Parliament APIs were already
# well covered. lda.data.parliament.uk - the UK Parliament's linked-data platform,
# which is where divisions, early day motions, written questions, election results
# and research briefings actually live - was entirely absent, as was the Canadian
# House of Commons member export and the Riksdag's speech register.
# Pipe-delimited. Columns: id|mode|want|category|record_type|tags|portal|name|name_ja|url|probe|description|opts
#
# Engine notes for this beat:
#  * the UK linked-data platform pages on `_page`, which is 0-based. It contains
#    neither "offset" nor "start" nor "skip", so without page_zero_based=1 the
#    engine coerces page_start to 1 and page 0 - the first page of results - is
#    fetched once and then never revisited, while page 1 is fetched twice.
#  * `_pageSize=500` is the platform's maximum; asking for more silently returns
#    500 anyway.
#  * ourcommons.ca serves XML with the record element <MemberOfParliament>;
#    array_path names it so the auto-detector cannot pick a more numerous leaf.
