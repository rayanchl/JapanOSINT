# Batch 34 beat fdsnstation — FDSN station/1 inventories on the 18 data centres whose /fdsnws/ base is already wired for another service.
# NOT PROBED (no outbound HTTPS this session). The host is proven reachable by an existing row; the service path and the pipe-delimited
# text schema (Network|Station|Latitude|Longitude|Elevation|SiteName|StartTime|EndTime) are fixed by the FDSN specification.
# csv_delim=pipe is declared deliberately: the engine's CSV delimiter DEFAULTS TO COMMA with no sniffing, so a pipe-delimited FDSN
# response read without it lands the whole line in one cell and every column key resolves to nothing. hp3b31's IRIS row has that defect.
# id_keys is the network+station+start composite because a station CODE alone is not unique across networks (rule 4b).
