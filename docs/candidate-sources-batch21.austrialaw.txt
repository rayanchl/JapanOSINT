# Batch 21 - austrialaw: the Austrian Rechtsinformationssystem (RIS) OGD API.
#
# SCOPE. RIS is the Federal Chancellery's own legal database and the only
# authentic publication channel for Austrian federal and state law. The tree
# already carried six RIS endpoints - bundesrecht and landesrecht by Titel, and
# the Judikatur applications Justiz, Vfgh and Dsk. Every OTHER application the
# v2.6 API serves was missing, and they are not variations on the same data:
# each Applikation is a separate register with its own schema.
#
# What the API actually accepts was established by probing, not by reading
# documentation. There are exactly three endpoint paths - bundesrecht,
# landesrecht and judikatur - and the register is selected by the Applikation
# query parameter. Every other spelling tried (Bundesnormen, Erlaesse,
# Gemeinderecht, Begut, Regv, Kundmachung, Normenliste, Avsv, Vbl,
# Gesamtabfrage as PATHS) answers 404, and an invalid Applikation answers
# HTTP 200 carrying a SOAP schema-validation error document rather than an
# error status - so a row written from the documentation would have registered
# as live and stored a validation message as a finding.
#
# Pagination is Seitennummer, 1-based, with DokumenteProSeite in the URL.
# OneHundred is the largest accepted value; "Hundred" returns an empty result.
# Verified: Seitennummer=3 returns page 3 of 1522 hits, not page 1 again.
#
