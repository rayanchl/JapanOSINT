# Batch 19 — IANA, IETF and internet-governance authoritative registries.
#
# These are the registries that define what the identifiers in every other
# source in this tree actually mean. A port number, an AS number range, a TLD,
# an MCC/MNC pair or a language subtag is only interpretable against the
# authority that assigned it, and each of these files is that authority's own
# published copy. They are small, stable, and they make the rest of the
# registry self-describing.
#
# Pipe-delimited. Columns: id|mode|want|category|record_type|tags|portal|name|name_ja|url|probe|description|opts
# Generated into collectors/pivot/table/hp3_iana.c by tools/gen_hp_batch.py.
