# Batch 24 - jpbulk: four endpoints whose FILTER is ignored, registered as

# An API that accepts a filter and returns the whole collection anyway is
# unusable as an entity pivot - it attributes thousands of unrelated
# records to whatever was asked about, which is a confident wrong answer.
# It is perfectly good as a BULK source, where no per-entity claim is made
# and the whole collection is the point. Each row below states the measured
# filter behaviour in its own description so the reason is not lost.
