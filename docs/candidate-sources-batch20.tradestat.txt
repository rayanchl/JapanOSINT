# Batch 20 - tradestat: customs trade registers and statistical-office catalogues.
# HMRC's uktradeinfo OData service, Singapore's TableBuilder and the BIS SDMX
# structure registry were all absent from the tree; Finland's StatFin PxWeb root
# was reachable only through a different host. Together these give the trader
# register behind UK customs declarations, the port and commodity dictionaries
# that decode a UK trade record, and the structural metadata that makes an SDMX
# statistical warehouse queryable at all.
# Pipe-delimited. Columns: id|mode|want|category|record_type|tags|portal|name|name_ja|url|probe|description|opts
#
# Engine notes for this beat:
#  * OData pages on $skip, which is 0-based but does NOT contain the substring
#    "offset", so the engine would coerce page_start to 1 and step past the first
#    record of every page. page_zero_based=1 is set on every uktradeinfo row.
#  * $top is set to 1000 and page_size matches it, so the offset step is never
#    larger than the page the server actually returns.
#  * the BIS SDMX-JSON structure responses nest the record list one level below a
#    per-artefact key (data.codelists, data.dataStructures ...). Each artefact
#    object also holds its own inner array, which is denser, so array_path is
#    mandatory or the engine keys records off the wrong level.
