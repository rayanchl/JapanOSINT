# Audit of 2026-10-02: the September merges, the engine, the embedding pipeline

**Scope:** everything that changed between `64dc2f4` (2026-08-31) and `0309b17`
(2026-10-02, the merge reconciling origin/main's and the local integration of
PRs #21–#23). That is 1,079 files: core 2.9k lines, lib 1.9k, collectors 3.6k,
generated tables 64k, client 13k and docs.

**How it was reviewed:** six parallel reviews, one per area — embedding/semantic
pipeline, engine libraries, core services, hand-written collectors, web client,
and tools/CI with merge consistency. Each finding needed code evidence and a
concrete failure scenario, and most were confirmed by running a harness or the
real binary against a scratch DB.

**How it was fixed:** six fix branches, merged into `fix/audit-2026-10-02`:
`fix/core` a54430f, `fix/embed` 44047e8, `fix/client` 64498c8, `fix/sources`
6fd6db0, `fix/tools` fe2fb53 and `fix/lib` 9d74ee7. On top of them:
- bf36889 — SIDOF, CORDIS, `{date:}`, `a+b` array_path;
- a3b26ee — tenancy;
- 5838c63 — audit markers;
- 93f6351 — the last `strcasestr`.

**Final verification**, on the merged branch with a scratch `JO_DB`:
- `make` 0 warnings; selftest, unit, hptest, authtest, pagewalktest,
  htmlparsetest, lint-sources, source-floor and registry-floor (18,170) pass.
- audit-sources: 0 findings over 1,650 files (strict 0 / 282).

## Fixed, by area (highest severity first)

**Web client** (64498c8 — 99 tests, 37 new; checked in headless Chromium on
the production build)
- **The map never loaded.** maplibre 6's worker was not bundled. Now
  `setWorkerUrl` via `?worker&url`.
- **deck.gl crashed every frame** reading the `map.transform` maplibre 6
  removed. Fixed with a shim. No deck release supports 6, and every maplibre 5.x
  carries GHSA-jrc7-96c5-q579 (critical), so 6.11.2 stays.
- **Place labels were never harvested.** Hidden layers are not placed; they
  are now hidden by opacity.
- **Two loops removed.**
  - Reverse geocode re-rendered 1,079 times in 1.5 s; now 2.
  - Intel Recent sent 69 COUNT requests in 3 s; now 1.
- **Login-CSRF in the OAuth callback** (implicit-hash tokens). It is now
  PKCE-only, with a nonce checked against the tab that started sign-in.
- **The camera iframe accepted `javascript:`.** `isSafeUrl` is now checked on
  both branches.
- **Request and response mismatches fixed:**
  - `depart` became `depart_at`;
  - `has_geom: '1'` became `'yes'`;
  - the consent call sends `{consent}`;
  - probe and consent responses are merged into the row instead of replacing it;
  - the score is read from `rerank`.
- **Timestamps** were parsed as local time.
- **Invented totals** ("showing 100 of 101") and silent list caps now say
  "N loaded · more on server", or page through.
- **Sign-out** now revokes the refresh token and clears per-account browser
  state.

**Embedding pipeline** (44047e8)
- **Delta walk stalled forever.** It rescanned the same 2,000 re-fetched
  uids and never embedded new rows. Now it marks seen rows and keeps a
  persistent keyset. Measured: 2,000 unchanged re-fetches plus 5 new rows
  embed exactly the 5.
- **One bad row stopped the sweep for good.** Now there is per-row retry, an
  `intel_vec_failed` table, and a `failed_count` in coverage.
- **A semantic query froze the HTTP server.** It now runs on a worker thread
  with a queue deadline; `/api/health` answers in under 1 ms meanwhile.
- **Model stored as "unknown" when `/v1/models` failed**, after which the pod
  refused forever. A failed detection now skips the tick.
- **Same-dimension model swap undetected** by search and `service_vec`. It
  now gets a 503 and an identity check.
- **Non-ISO dates made rows ineligible** (552 rows in the test).
- **BEGIN unchecked; one failed probe dropped a good service index; failed
  inserts still marked the index ready.**
- **Service cards were sent to the LLM unbudgeted.**
- **Same-second rows skipped; `tenant_withheld` leaked other tenants' match
  counts; a duplicated `index` in a response was stored as a zero vector.**
- **Docs said cosine.** The metric is L2, whose ranking equals cosine for unit
  vectors.

**Core** (a54430f, plus a3b26ee and 93f6351)
- **WAL checkpoint pod.** A 20 s TRUNCATE held the writer lock past every
  writer's 5 s busy timeout, so emits failed silently. It now runs PASSIVE
  first, then TRUNCATE with 1 s attempts, and restores busy_timeout. Refused
  emits now show on the run line as `failed=N EMIT-FAILED`.
- **Dispatcher name resolution** ran the resolved source under the misspelled
  id and blamed the healthy source. It also considered bulk rows; it now
  considers entity pivots only.
- **Notices were counted as data** by dispatch, and inside `stored=` (which hid
  a collision). Stored is now compared against records minus notice uids.
- **Cross-tenant reads:**
  - search runs by `request_id` and the pre-auth stream are now owner-tenant or
    `stream_key` only;
  - investigation rows were written under the shared tenant, and the intel
    feed, search and item routes never resolved the tenant (a3b26ee).
- **25 of 89 API keys** could never be listed or set (a 64-entry cap).
- **Exports:**
  - a use-after-free on shutdown in the binary reply path;
  - OOM reported as "client gone", and 3× peak memory (cut where cheap);
  - a known-failed export sent as 200.
- **Smaller fixes:**
  - the report thread lost its body;
  - the overlay load raced;
  - the status cache could be bypassed;
  - `stored` counted rows whose COMMIT failed;
  - case notes always 400;
  - the maintenance digest offered "Approve" without showing the URL patch;
  - the last GNU-only `strcasestr`.

**Engine libraries** (9d74ee7)
