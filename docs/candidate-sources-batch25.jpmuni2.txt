# and jpmunireserve did not take. Discovery: Wikidata (P31 city/core/designated,
# P856 site, P1082 >= 100k, plus the 7 uncovered Tokyo special wards) gave 165
# uncovered town halls; each home page was read for <link rel=alternate>, every
# rss/rdf/feed-looking href, its RSS index page, and 40 fixed CMS feed paths.

# catalogues came from search.ckan.jp/sites and the e-Gov "open-data adopting
# municipalities" CSV (1,527 rows): 14 municipal CKAN APIs, 1 package_list-only
# CKAN, 2 ArcGIS Hubs, 2 WordPress REST news streams and 5 Dataeye HTML
# listings answered. Municipal disaster e-mail archives on the ktaiwork
# platform were enumerated by slug (32 live tenants, 27 with items).
# Council-minutes systems (kaigiroku.net, kensakusystem.jp) were probed and
# rejected: both are POST/CGI search apps with no feed or JSON surface.
