# Batch 25 - jpnatgov: Japanese national government and quasi-government bodies whose HOSTS are
# absent from the tree. Regional offices of the ministries (財務局 x10, 労働局 x40+, 運輸局, 地方整備局,
# 経済産業局), independent administrative agencies (独立行政法人), the House of Councillors' own
# bill/member/question/petition registers, the Cabinet's 行政事業レビュー (RS system) REST API - the
# only public machine-readable record of every budgeted government programme and its payees - the
# e-Gov CKAN catalogue, the transport safety board's accident-report indexes, and the ministries'
# press/procurement lists that have no feed and were taken as HTML anchor lists.
# Pipe-delimited. Columns: id|mode|want|category|record_type|tags|portal|name|name_ja|url|probe|description|opts
#
# Harvest: 121 homepages fetched for <link rel=alternate>/feed hrefs, 133 guessed feed paths, 112
# WordPress wp-json probes, 96 HTML list pages + 76 labour-bureau feed probes, plus API discovery by
# reading rssystem.go.jp's bundled JS. Every row below was fetched live on 2026-08-29 with HTTP 2xx and
# >=2 real records in the declared mode; pivot rows were also asked about an impossible entity
# (zzqxv9 / ゼゼゼゼゼゼ) and returned empty. Probed ~420 URLs; kept 150; rejected 164 (see
# docs/rejected-sources-batch25-jpnatgov.tsv). Feeds that answered 200 with zero <item> (many
# prefectural labour bureaus) are EMPTY_RESULTSET rejects, not rows.
#
# Sangiin HTML rows: the anchors are directory-relative ("./meisai/m221…htm", "../profile/7007006.htm")
# and the session number (221) is baked into the path; the manifest cannot express "follow the current
# session", so these rows will need re-pointing when a new Diet convenes. base= is the page directory.
#
