# Batch 20 - airspace: the PENDING side of the FAA's 28-day NASR cycle, the six
# current-cycle layers the tree does not already carry, and the two OurAirports
# reference tables that were missing.
#
# SCOPE. The tree already registers the FAA's current-cycle NASR layers three
# times over - collectors/sources/av_faa_arcgis.c composes fourteen of them at
# runtime, hp3b19_transport.c carries six more and the vsrc_aviation_* feeds
# carry the rest. tools/batch_exclusions.py sees none of the runtime-composed
# ones and treats f=geojson and f=json as different endpoints, so it reported no
# collision; the duplication was found by diffing layer NAMES instead. Forty-one
# rows were removed from this batch on that finding.
#
# What is left is what nobody had taken: the Pending_* family, which is the next
# chart cycle's airspace, routes, navaids, frequencies and airport surfaces as
# they WILL be, published weeks before they take effect. Diffed against the
# current layer, each one is forward notice of a change.
#
# Pipe-delimited. Columns: id|mode|want|category|record_type|tags|portal|name|name_ja|url|probe|description|opts
# Every row returned real records over the wire via tools/probe_hp_batch.py and
# was then proven to EMIT through the real binary by tools/audit_batch_emit.py.
#
# Engine notes for this beat:
#  * array_path=features is mandatory. The ArcGIS response also carries a `fields`
#    array (the layer schema) which is denser than `features` on a small page, so
#    the engine's auto-detection would key every record off the schema, not the data.
#  * resultOffset paging is 0-based; page_zero_based=1 is declared even though the
#    engine already skips the coerce-to-1 for a param whose name contains "offset".
#  * resultRecordCount=1000 is at or below every one of these layers' maxRecordCount
#    (measured: 1000 or 2000), so a page is never shorter than the offset step and
#    no record is stepped over.
#  * the service enforces a 6000 request-unit per minute quota and answers over it
#    with HTTP 200 and an {"error":{"code":429}} document. See the defect note in
#    docs/verified-sources-batch20.md - the engine files that document as a record.
