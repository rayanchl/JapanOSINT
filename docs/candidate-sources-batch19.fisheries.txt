# This beat's agent was killed mid-discovery by the session limit and left no
# manifest, only its downloaded WFS GetCapabilities documents. The layer names
# below are read from those documents rather than guessed, and every row here
# was re-fetched and confirmed to return real features before being written.
#
# Deliberately NOT here: Global Fishing Watch (bearer token required),
# UCDP (401, token required), the ICCAT/IOTC/IATTC records of authorised
# vessels (HTML tables behind a session, no machine-readable export), and
# CCAMLR's GeoServer (answers an XML ServiceException for every typeName tried).
# A source that cannot be fetched keylessly is left out rather than registered
# to fail on every run.
#
# No maxFeatures/count cap is declared on the WFS rows: the layer is the record
# set, and asking for a slice of it would discard the rest of a request we have
# already paid for. FAO_MAJOR is ~15 MB with geometry; lib/jsonstream.c exists
# precisely so a bulk register that size is reachable.
